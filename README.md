One funny line in one line (84 characters): dating apps reveal that "my type" is not a person but a photograph — someone pictured next to a boat they do not own. The program writes that single line to /output/entry.txt. Fourteen candidates were written for this entry and ranked in two rounds of strict external review against the judge's published brief (a stranger must get it in one read, the expectation must break, the laugh must land at the end, and the line must not be a stock joke); the boat line won both rounds, and four evidence-earning revisions of it were tested and rejected on logic in round two, leaving the clean original as the final text.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
